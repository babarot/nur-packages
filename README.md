# nur-packages

Nix packages for [babarot](https://github.com/babarot)'s tools.
Each `pkgs/<name>/default.nix` is generated by [GoReleaser](https://goreleaser.com/customization/nix/) when the tool is released, from the prebuilt release binaries.

## Usage

```sh
nix run github:babarot/nur-packages#naminator
```

As a flake input:

```nix
inputs.babarot.url = "github:babarot/nur-packages";
# ...
home.packages = [ inputs.babarot.packages.${pkgs.stdenv.hostPlatform.system}.naminator ];
```

## Adding a tool

Add a `nix` section to the tool's `.goreleaser.yaml` pointing at this repository. See [babarot/naminator](https://github.com/babarot/naminator) for an example.
